# Adidas Quarterly Revenue Analysis and Forecasting

Time-series analysis and forecasting of Adidas quarterly revenue using Python.

## What this project does
- Prepares the data (date conversion, missing value checks)
- Plots quarterly and yearly revenue trends and the revenue distribution
- Analyses seasonality and autocorrelation (seasonal decomposition, ACF/PACF)
- Creates lag and rolling-average features
- Forecasts revenue with ARIMA, SARIMAX and Prophet
- Evaluates models with RMSE, MAE, MAPE and R-squared

## Files
- `adidas-quarterly-sales.csv`: the dataset
- `adidasquartlysales.ipynb`: the analysis notebook

## Tools
Python, pandas, Matplotlib, Seaborn, statsmodels, scikit-learn, Prophet
